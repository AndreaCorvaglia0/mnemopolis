# Mnemopolis

Memory towns for active learning: a subject becomes a small town, every house holds one idea,
and you learn it by doing before you are asked to remember it.

These pages explain why the game is built the way it is. The specification is in
[`docs/DESIGN.md`](https://github.com/AndreaCorvaglia0/mnemopolis/blob/main/docs/DESIGN.md);
the method for designing a course is in `skills/knowledge-base/`.

## The position in five lines

1. Curiosity is the engine. In a game its name is mystery.
2. You cannot remember well what you have not understood. Understanding is built by doing.
3. A map of the subject and a map of a place are the same thing seen twice.
4. Game dynamics serve three different needs: proving, exploring, practising. They should not
   be mixed up.
5. The basic path is short, explicit and finishable. Everything else is optional and hidden on
   purpose.
