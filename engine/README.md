# Mnemopolis engine

A pixel-art town generated from a course database, with labs, reading walls, a map and review
questions. The course lives in `src/course/`. Everything else is the engine.

    npm install
    npm run check     # validate the course
    npm run build     # dist/index.html, one self-contained page
    npm run shots     # screenshot tour in ./shots (needs Chrome)

Documentation: `docs/` here, and `../AGENTS.md` for the whole pipeline.
The demo course is "Chroma Town", a short course on colour.
